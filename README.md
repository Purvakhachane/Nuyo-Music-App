🎵 Nuyo Music – Streaming App

📌 Overview

Nuyo Music is a web-based music streaming application that provides users with a smooth and engaging way to listen to their favorite songs. The app is designed with a modern UI and focuses on performance, usability, and a personalized user experience.

...

🚀 Features : 

🎧 Real-time music streaming

🔍 Search songs, artists, and albums

📂 Create and manage playlists

❤️ Like and save favorite songs

⏯️ Music controls (play, pause, skip, repeat)

📱 Responsive design (mobile + desktop)

🌙 Optional dark mode

...

🛠️ Tech Stack

Frontend: HTML / CSS / JavaScript

Backend: Node.js

APIs: Music streaming API / Custom backend API

Version Control: Git & GitHub
